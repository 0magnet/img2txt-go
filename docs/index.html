img2txt-go — images to colored ASCII and ANSI art

A Go port of libcaca's img2txt by Sam Hocevar and Jean-Yves Lamoureux. It converts images to colored character art and to every text format libcaca supports — ANSI, HTML, IRC, BBCode, PostScript, SVG, TGA and more — with no cgo, no libcaca and no Imlib2 behind it. A single static binary.

Drop an image in, pick a width, a dithering algorithm and an output format, and it runs the same pipeline the command-line binary does. The conversion happens in WebAssembly in the page, so the image never leaves the tab and is never uploaded anywhere.

Source code: github.com/0magnet/img2txt-go. More Go and WebAssembly projects: magnetosphere.net/software.
